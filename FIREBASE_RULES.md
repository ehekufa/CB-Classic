# Правила Firebase для CB-Classic

База (Realtime Database): **https://circlebattle1-default-rtdb.firebaseio.com/**

Этот файл — на посмотреть и на вставить в консоль Firebase. Когда переключаемся на
правки, которые онлайна не касаются, файл удаляется (по договорённости); как только
снова нужен онлайн — создаётся заново.

Как игра ходит в базу (официальный REST-протокол RTDB, `src/cpp/fbnet.cpp`):

* запись — `PATCH https://…/world.json` и `PATCH https://…/Имя/Пароль.json`
  (несколько значений одним запросом);
* чтение — опрос узлов `GET https://…/world.json` и `GET https://…/Имя/Пароль.json`
  примерно раз в 0,35 с;
* весь обмен идёт в отдельном потоке, кадр игры сеть не ждёт.

---

## 1. Как применить

1. Открыть <https://console.firebase.google.com/> → проект **circlebattle1** →
   *Realtime Database* → вкладка **Правила** (Rules).
2. Стереть всё, что там есть, вставить JSON из раздела 2 целиком.
3. Нажать **Опубликовать** (Publish). Применяется сразу, пересборка игры не нужна.
4. Проверить по разделу 4.

## 2. Правила (копировать целиком)

Готовый файл — **`firebase-rules.json`** (в нём только JSON, без текста). Ниже он же
для копирования из документации; `tests/check_fb_rules.py` следит, чтобы копии не
разошлись.

```json
{
  "rules": {
    ".read": false,
    ".write": false,

    "world": {
      ".read": true,
      ".write": true,
      ".validate": "newData.hasChildren()",
      "$key": {
        ".validate": "(newData.isNumber() && newData.val() >= -100000 && newData.val() <= 100000) || (newData.isString() && newData.val().matches(/^.{0,200}$/))"
      }
    },

    "$имя": {
      ".read": true,
      ".write": true,
      ".validate": "newData.isNumber() || newData.hasChildren()",

      "$пароль": {
        ".read": true,
        ".write": true,
        ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 1000000",

        "К": { ".read": true, ".write": true, ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 1000000" },
        "В": { ".read": true, ".write": true, ".validate": "newData.isNumber() && newData.val() >= 0 && newData.val() <= 1000000" },

        "$прочее": { ".validate": false }
      }
    }
  }
}
```

## 3. Что эти правила делают

| Путь | Что это | Кто пишет |
|---|---|---|
| `Имя/Пароль` | старый суммарный счёт кубков | сцена 77 (регистрация) |
| `Имя/Пароль/К` | кубки | сцены 1, 26 |
| `Имя/Пароль/В` | валентинки | сцены 1, 26, 31, 95 |
| `world/X1…Y5`, `world/Rotate4/5`, `world/X404/Y404/Rotate404` | позиции врагов в онлайне | сцены 95, 99 |
| `world/Ивент`, `world/Написано` | событие/объявление от админа | сцены 99, 95 |
| `world/Какой скин у … куба` | скин куба в онлайне | сцена 95 |

Защита:

- **нельзя прочитать базу целиком** (`".read": false` в корне) — значит нельзя выкачать
  список всех игроков или снести всё одной записью;
- **нельзя писать мимо известных узлов**: снаружи разрешены только `world` и узлы
  игроков, а внутри узла игрока — только `К` и `В`;
- **значения проверяются**: числа в разумных диапазонах, строки не длиннее 200
  символов — не получится залить в базу мегабайт.

Чего эти правила **не** делают (и не могут без входа в аккаунт):

- любой, кто знает `Имя/Пароль`, может прочитать и перезаписать чужой счёт —
  клиент ходит в базу анонимно, без `auth`;
- настоящая приватность («мой счёт может менять только мой телефон») требует
  **Firebase Authentication** (анонимный вход) и правил вида
  `"$имя": { ".write": "auth != null && $имя === auth.uid" }`.
  Это отдельный шаг — скажи, если делать.

## 4. Проверка после публикации

В терминале (или в браузере):

```bash
# 1) должно ответить содержимое узла (его читать разрешено)
curl 'https://circlebattle1-default-rtdb.firebaseio.com/world.json'

# 2) должно ответить Permission denied (всю базу читать нельзя)
curl 'https://circlebattle1-default-rtdb.firebaseio.com/.json'

# 3) запись числа — 200 OK
curl -X PUT 'https://circlebattle1-default-rtdb.firebaseio.com/world.json' -d '{"X1":10}'

# 4) запись мусора — отклоняется правилами
curl -X PUT 'https://circlebattle1-default-rtdb.firebaseio.com/world.json' -d '{"X1":"abc"}'
```

## 5. Как это проверено без интернета

`tests/firebase_mock.py` — мини-эмулятор базы, повторяющий REST-протокол
(GET/PUT/PATCH/DELETE по `путь.json`). Самотесты `tests/run_tests.sh` поднимают его
на `127.0.0.1:8899` и проверяют оба направления:

* чтение: в базе лежит `Гость/123/К = 777` → игра после пары кадров видит это
  значение (`--fb-url http://127.0.0.1:8899/`);
* запись: промокод «Lover» на сцене 31 → в эмуляторе базы появляется
  `Гость/123/В = 20`.

На телефоне тот же код идёт в настоящую базу по HTTPS (TLS на стороне Java,
`android/app/src/main/java/org/cbclassic/FirebaseNet.java`).
