# Скриншоты прогонов

Кадры из настоящего движка (`build/cb-classic --frames 25 --scene N --out ...`).
Движок пишет PNG без сжатия (свой deflate только «stored»), поэтому файлы здесь
пересжаты: `convert in.png -strip -define png:compression-level=9 out.png`.

* `scene_1.png` — меню (сцена 1);
* `scene_26.png` — «Игра»: джойстик, атака, кубики, «назад», мод-меню;
* `scene_27.png` — «Кубы»;
* `scene_70.png` — «Режимы»;
* `scene_80.png` — «Классы»;
* `scene_96.png` — «Достижения»;
* `scene_77_input.png` — «Регистрация» с введёнными именем и паролем
  (поле пароля в фокусе, видна каретка) — кадр из
  `--script tests/scripts/input_registration.txt`.

Важно: при прямом запуске сцены (без сцены «Загрузка», 42) фон остаётся белым —
цвет фона выставляется скриптами загрузочной сцены (`setBackgroundColorHex`) и
«живёт» в состоянии движка. Чтобы увидеть оригинальные цвета, начинайте с
`--scene 42` или задавайте фон в сценарии.
